# Шрифты

Используются только при генерации SVG (текст переводится в контуры), в браузер не грузятся.
Все шрифты — Google Fonts под лицензией [SIL Open Font License 1.1](https://openfontlicense.org):

Unbounded, Manrope, JetBrains Mono, Monoton, Playfair Display, Press Start 2P,
Rubik Glitch, Permanent Marker, Orbitron, Major Mono Display, Bungee Shade.
